# Агрегатор новостей (GitHub Pages)

Статический сайт-агрегатор: выбираете одну или несколько категорий, получаете общую ленту свежих новостей.

Возможности:
- выбор нескольких категорий;
- карточки с картинкой и кратким описанием;
- бесконечная лента (порционная отрисовка);
- просмотр текста в модальном окне + ссылка на первоисточник.

## Как включить GitHub Pages
1. Запушьте репозиторий в GitHub.
2. GitHub: Settings -> Pages.
3. Source: "Deploy from a branch".
4. Branch: `main` / folder: `/ (root)`.

После этого откройте Pages URL.

## Локальный запуск
Можно открыть `index.html` напрямую, но надёжнее через локальный сервер:

```bash
node dev-server.js
```

## Откуда берётся текст новостей
Браузер **не может надёжно** скачать «полный текст» с сайтов новостей напрямую (CORS/пейволлы/защита).
Поэтому лента читает готовый срез `data/news.json`, который собирается отдельным скриптом.

Сгенерировать данные локально:

```bash
npm install
npm run build:data
node dev-server.js
```

Источники и правила категоризации настраиваются в `data/feeds.json`.

## Авто-обновление на GitHub
В репозитории есть workflow `/.github/workflows/update-data.yml`, который (по расписанию и вручную) обновляет `data/news.json` и коммитит его в `main`.

## Примечания
- Текст в модальном окне извлекается автоматически (Readability) и может быть неполным или отсутствовать для отдельных сайтов.
